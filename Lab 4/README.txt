# Alumni Management System — Lab 04

Completed HTML5 + CSS3 implementation for Lab-04.

## Files
- index.html — dashboard/main page
- alumni.html — alumni directory
- profile.html — alumni profile card
- register.html — alumni registration form
- css/style.css — external CSS stylesheet

## Run
Open `index.html` in a browser.

No Bootstrap or Tailwind is used. All styling is in the external stylesheet.
