# Alumni Management System
Features: EJS form, image/resume upload, MySQL, CRUD, search, individual PDF, all-record PDF.
Run: npm install, import database.sql, node app.js, open http://localhost:3000.
Routes: /, /register, /view/:id, /edit/:id, /delete/:id, /pdf/:id, /pdf.
Max upload size: 2 MB. Images JPG/JPEG/PNG/GIF; resume PDF/DOC/DOCX.
Classroom note: use password hashing in real applications.
